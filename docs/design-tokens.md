# Дизайн-токены

Источник: [Advisor — Astrology App | Mobile UI Kit](https://www.figma.com/design/493l8QKB5vndt5VRYEfEoT/) в Figma.

## Цвета

### Основная палитра

| Назначение | HEX | Описание |
|---|---|---|
| Фон (Deep Space) | `#0B0C10` | Основной фон приложения |
| Золотой акцент | — | Акценты, рамки кнопок, линии натальной карты |
| Фиолетовый акцент | — | Вторичные акценты |

### Скрин-цвета (из app.json)

| Назначение | HEX |
|---|---|
| Фон сплеш-экрана | `#1a1a2e` |
| Android adaptive icon фон | `#1a1a2e` |

### Статусные цвета

| Состояние | Описание |
|---|---|
| Удача | Неоновая шкала на Dashboard |
| Любовь | Неоновая шкала на Dashboard |
| Карьера | Неоновая шкала на Dashboard |

> Точные HEX-коды золотого, фиолетового и неоновых цветов нужно извлечь из Figma-макета и добавить сюда при настройке темы Tamagui.

## Шрифты

| Роль | Стиль | Использование |
|---|---|---|
| Заголовки | Serif | Заголовки экранов, названия планет |
| Основной текст | Sans-Serif | Тела текста, подписи, кнопки |

> Конкретные названия шрифтов и размеры определяются при настройке Tamagui-темы (шаг 1 плана).

## Геометрия

| Параметр | Значение |
|---|---|
| `border-radius` (карточки) | `16px` |
| `border-radius` (кнопки) | `9999px` (pill) |
| Основные паддинги | Определяются из макета |

## Структура для tamagui.config.ts

При настройке темы токены будут перенесены в `tamagui.config.ts`:

```ts
// Пример структуры (точные значения — из Figma)
const tokens = {
  colors: {
    background: '#0B0C10',
    gold: '#...',      // из Figma
    purple: '#...',    // из Figma
    neonLuck: '#...',
    neonLove: '#...',
    neonCareer: '#...',
  },
  radii: {
    card: 16,
    button: 9999,
  },
}
```

## Экспорт графики

Все иконки планет и знаков зодиака из Figma UI Kit экспортируются в **SVG** и складываются в `/assets/icons/`. Текущий статус: иконки не экспортированы.
