# Сценарий экранов — «Карта предсказаний»

## Общая логика

Приложение проходит пользователя через 4 экрана, собирая данные для предсказания:

1. **Дата рождения** → определяет знак зодиака, планеты, дома
2. **Планеты + Имя** → визуализация планет, ввод имени
3. **Время и место** → уточнение данных для точного расчёта натальной карты (опционально)
4. **Карта предсказаний** → благоприятные и напряжённые сферы на текущий момент

---

## Экран 1: Дата рождения (существующий)

**Содержимое:**
- Звёздное небо на фоне (Skia, 60 звёзд, мерцание + дрейф)
- `DatePicker` — выбор даты (день/месяц/год)
- Кнопка «Далее»

**Данные на выходе:** `birth_date` (строка `YYYY-MM-DD`)

---

## Экран 2: Планеты и имя ✅ (реализовано)

> **Статус:** Базовый экран готов. Дата рождения передаётся с экрана 1. Поле ввода имени работает. Звёздный фон переиспользован. Skia-планеты пока не добавлены (ждём этапа визуализации).

### Фон
- Звёздное небо (компонент `StarryBackground`, переиспользовать с экрана 1)
- Две планеты диаметром 35px, отрисованные через **Skia** (`Circle` + градиент):
  - **Первая планета — Солнце** (всегда, для всех дат)
  - **Вторая планета — управитель дня недели** даты рождения:
    | День недели | Планета | Цвет |
    |---|---|---|
    | Воскресенье | ☉ Солнце | — |
    | Понедельник | ☽ Луна | #C0C0C0 (серебро) |
    | Вторник | ♂ Марс | #E74C3C (красный) |
    | Среда | ☿ Меркурий | #F1C40F (жёлтый) |
    | Четверг | ♃ Юпитер | #3498DB (синий) |
    | Пятница | ♀ Венера | #2ECC71 (зелёный) |
    | Суббота | ♄ Сатурн | #8E44AD (фиолетовый) |

  - Планеты парят и медленно вращаются друг вокруг друга (анимация через Reanimated shared values)

### Контент
- Заголовок: название знака зодиака (определяется по `birth_date`) + иконка знака
- Короткий текст: *«Ваша планета-управитель — {название}. Она определяет ваш характер...»*
- Поле ввода имени (Tamagui `Input` или стилизованный `TextInput`)
- Кнопка «Далее»

**Данные на выходе:** `birth_date`, `name`

---

## Экран 3: Время и место рождения (опционально)

### Фон
- Звёздное небо

### Контент
- Заголовок: *«Где и когда вы родились?»*
- Поле выбора времени: `DatePicker` (только часы:минуты) или упрощённый picker
- Поле поиска города: `TextInput` с поиском по `GET /api/v1/geo/cities?q=...`
  - Выпадающий список найденных городов
  - Выбор города подтягивает `latitude`, `longitude`, `timezone`
- Кнопка «Пропустить» (скипает экран, город/время не сохраняются)
- Кнопка «Далее»

**Данные на выходе (если не пропущено):** `birth_time`, `latitude`, `longitude`, `timezone`

---

## Экран 4: Карта предсказаний

### Что происходит
На этом экране приложение использует данные пользователя и **текущую дату** для расчёта **транзитов** — где сейчас находятся планеты относительно натальной карты пользователя.

### Фон
- Звёздное небо с планетами (несколько планет, соответствующих активным транзитам)

### Логика расчёта сфер
Бэкенд умеет считать положения планет на любую дату (через VSOP87). На 4-м экране нужно:

1. **Взять натальную карту пользователя** (положения планет в момент рождения) — из кэша `user_chart_placements` или рассчитать на лету
2. **Рассчитать текущие транзиты** — положения планет на сегодня (`service.ChartService` может принять любую дату, не только дату рождения)
3. **Сравнить углы** между натальными и транзитными планетами:
   - **Соединение (0°)** — планета активирует натальную, усиливает сферу
   - **Квадрат (90°)** — напряжение, трудности, вызовы
   - **Тригон (120°)** — гармония, удача, лёгкость
   - **Оппозиция (180°)** — противостояние, конфликт
4. **Определить сферы** по дому транзитной планеты:
   - 1-й дом: личность, здоровье
   - 2-й дом: финансы, ценности
   - 3-й дом: общение, обучение
   - 4-й дом: дом, семья
   - 5-й дом: творчество, любовь
   - 6-й дом: работа, здоровье
   - 7-й дом: партнёрство, брак
   - 8-й дом: трансформация, кризисы
   - 9-й дом: путешествия, философия
   - 10-й дом: карьера, статус
   - 11-й дом: друзья, цели
   - 12-й дом: подсознание, уединение

### UI
- **Благоприятные сферы** (тригоны/соединения): зелёная карточка с текстом *«Отлично подходит для...»*
- **Напряжённые сферы** (квадраты/оппозиции): красная/оранжевая карточка с текстом *«Будьте готовы к трудностям в...»*
- Нейтральные сферы не показываются
- Анимация появления карточек (с задержкой)

### Пример предсказания

```
Благоприятно:
  💰 Финансы — Юпитер в тригоне к вашему Солнцу.
    Отличное время для инвестиций и крупных покупок.

  ❤️ Отношения — Венера в соединении с натальной Венерой.
    Гармония в паре, романтика, взаимопонимание.

Напряжённо:
  🏢 Карьера — Марс в квадрате к Сатурну.
    Возможны задержки в проектах, конфликты с начальством.
    Проявите терпение и не принимайте поспешных решений.
```

### Если пользователь пропустил экран 3
- Показывать менее точное предсказание (только по знакам, без домов)
- Использовать упрощённую модель: только планета в знаке + транзиты по знакам

## Технические заметки

### Новые компоненты для Skia
- `PlanetOverlay` — отрисовка двух планет (Солнце + управитель дня) на фоне звёзд
- Планеты рисуются как `Circle` + radial gradient (Skia `Shader`/`RadialGradient`) + glow effect

### Новый API-эндпоинт (нужно на бэкенде)
Текущий бэкенд считает карту только при регистрации. Для экрана 4 нужен эндпоинт:
- `GET /api/v1/transits?date=2026-07-24` — текущие транзиты относительно натальной карты пользователя
- Или универсальный `POST /api/v1/calculate` — рассчитать положения планет на произвольную дату

### Хранение состояния
- `birth_date` — сквозной параметр через все экраны
- `name` — задаётся на экране 2
- `birth_time`, `latitude`, `longitude`, `timezone` — опционально, с экрана 3
- На экране 4 объединить натальные данные + текущие транзиты → предсказания

### Навигация
Потребуется `expo-router` или `@react-navigation/native` для переходов между 4 экранами. Навигация — плоская (не табы), последовательная: 1 → 2 → 3 → 4.
