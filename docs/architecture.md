# Архитектура приложения

## Обзор

Sprite App — одноэкранное Expo-приложение с managed workflow. На данный момент реализован один экран (ввод даты рождения). Полная архитектура описана ниже как план.

## Текущая структура

```
index.js          — точка входа, registerRootComponent
App.js            — корневой компонент, весь UI в одном файле
tamagui.config.ts — конфигурация Tamagui (тема по умолчанию)
```

Приложение использует `TamaguiProvider` с тёмной темой. Навигации нет — всё на одном экране.

## Планируемая архитектура

### Уровни

```
┌─────────────────────────────────┐
│           Screens               │  Экраны: Dashboard, NatalChart
├─────────────────────────────────┤
│         Components              │  Переиспользуемые компоненты:
│                                 │  Card, Accordion, Progress-bar
├─────────────────────────────────┤
│          Services               │  API-клиент, работа с SQLite
├─────────────────────────────────┤
│           Config                │  Tamagui тема, дизайн-токены
└─────────────────────────────────┘
```

### Навигация (план)

Пока не подключена. При добавлении нескольких экранов будет использоваться `expo-router` или `@react-navigation/native`.

### Компоненты (план)

| Компонент | Описание |
|---|---|
| `Card` | Базовая карточка с паддингами и скруглениями из макета |
| `Accordion` | Раскрывающийся список для интерпретаций натальной карты |
| `ProgressBar` | Неоновая шкала (Удача / Любовь / Карьера) |
| `NatalWheel` | Круг натальной карты на `react-native-skia` |
| `PlanetIcon` | SVG-иконки планет из `/assets/icons/` |

### State Management

На текущем этапе — локальное состояние (`useState`, `useRef`). При росте сложности может потребоваться Context или внешняя библиотека (Zustand и т.п.).

### API-слой (план)

Базовый fetch-клиент для работы с бэкендом. Основной эндпоинт:

- `GET /api/v1/profile/natal-chart` — координаты планет и тексты интерпретаций

Данные прокидываются: координаты → `NatalWheel`, тексты → `Accordion`.

### Хранение данных

`expo-sqlite` подключён как плагин в `app.json`, но пока не используется. Планируется для кэширования данных натальной карты и профиля пользователя.

## Зависимости и их роль

| Зависимость | Роль |
|---|---|
| `expo` | Сборка, dev-сервер, нативные модули |
| `tamagui` | UI-компоненты, тема, стили |
| `@react-native-community/datetimepicker` | Нативный picker даты |
| `expo-sqlite` | Локальная БД (планируется) |
| `expo-font` | Кастомные шрифты |
| `react-native-safe-area-context` | Безопасные зоны ( notch, home indicator ) |
| `react-native-skia` | 2D-графика для натальной карты (планируется) |
