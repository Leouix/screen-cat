## Важные

- **Timezone города не передаётся.** В данных есть `timezone` (`geo.js`, `cities_en.json`), но в `getPrediction` уходит только lat/lng (`api.js`). Для астрологии это критично по сути.

- **Мёртвый код (остатки):** `expo-sqlite` (в `package.json` и `app.json`, но нигде не используется), `dayjs` (не используется), проп `onSelect` прокидывается в `DeckCard`, но не используется (`AspectCardDeck.js:9`).

## Мелочи

- `Dimensions.get('window')` вместо `useWindowDimensions` в `StarryBackground.js:51` и `Earth3d.js:92` — устаревают при ресайзе.
- Нет персистентности — при рестарте все данные пользователя теряются (SQLite заявлен, но не подключён).
- Заголовки/надписи экранов местами «сырые» (`BirthDateScreen.js:61` — "when were you born?" без капса и т.п.).
