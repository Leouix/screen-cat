# Дизайн-токены

Источник: [Advisor — Astrology App | Mobile UI Kit](https://www.figma.com/design/493l8QKB5vndt5VRYEfEoT/) в Figma.

> **Статус:** `tamagui.config.ts` использует `defaultConfig` из `@tamagui/config/v5` без кастомных токенов — дизайн-токены пока задаются **непосредственно в компонентах** (см. `shared/StyledComponents.js` и экраны). При выносе токенов в Tamagui-конфиг их стоит перенести в этот документ.

## Цвета

### Основная палитра

| Назначение | HEX | Где используется |
|---|---|---|
| Фон (Deep Space) | `#0B0C10` | Основной фон приложения |
| Золотой акцент | `#f8df61` | Тексты, элементы пикеров даты/времени, акценты |
| Текст (приглушённый) | `#b2b2bc` | Подписи, вторичный текст |
| Текст (основной) | `#ffffff` | Заголовки, основной текст |
| Оверлей карточек | `#ffffff0a` | Фон карточек (напр. карточка выбранного аспекта) |
| Рамки карточек | `#ffffff20` | Границы карточек |
| Оверлей пикеров | `rgba(248, 223, 97, 0.15)` | Выделение активного элемента wheel-picker |

### Скрин-цвета (из app.json)

| Назначение | HEX |
|---|---|
| Фон сплеш-экрана | `#1a1a2e` |
| Android adaptive icon фон | `#1a1a2e` |

### Цвета планет

Планеты отображаются PNG-ассетами из `assets/planets/` (Skia-рендер не задаёт цвета). Цветовая кодировка планет-управителей по дням недели указана в `SCREENS.md`.

## Шрифты

| Роль | Стиль | Использование |
|---|---|---|
| Заголовки | Montserrat Bold (700) | Заголовки экранов, названия планет |
| Основной текст | Montserrat Medium (500) | Тела текста, подписи |
| Дополнительный | Montserrat SemiBold (600) | Акцентные тексты |
| Основной текст | Montserrat Regular (400) | Основной контент |

Шрифт подключается через `@expo-google-fonts/montserrat` (`useFonts` в `App.js`). В Tamagui-компонентах задаётся через `fontFamily="Montserrat_400Regular"` и т.п.

## Геометрия

| Параметр | Значение |
|---|---|
| `border-radius` (карточки аспектов) | `16px` |
| `border-radius` (оверлеи пикеров) | `8px` |
| Кнопки | Скруглённые (pill), прозрачные с рамкой / сплошные |
| Основные паддинги | Определяются в компонентах |

## Структура для tamagui.config.ts

Токены пока не перенесены в конфиг. Ориентировочная структура:

```ts
const tokens = {
  colors: {
    background: '#0B0C10',
    gold: '#f8df61',
    textPrimary: '#ffffff',
    textMuted: '#b2b2bc',
    cardOverlay: '#ffffff0a',
    cardBorder: '#ffffff20',
  },
  radii: {
    card: 16,
    overlay: 8,
  },
}
```

## Экспорт графики

Иконки планет экспортированы как PNG в `/assets/planets/` (используются в `PlanetImage` / `NameScreen`). SVG-иконки знаков зодиака не используются.
