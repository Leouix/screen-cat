## Как дать агенту доступ к дизайну?

В идеальном мире ты просто кидаешь агенту ссылку на Figma, но на практике (чтобы верстка не «поплыла» и цвета совпали на 100%) лучше всего подготовить для него **цифровые слепки** дизайна. Сделай три простых действия перед запуском агента:

1. **Вытащи дизайн-токены:** Открой макет в Figma, посмотри параметры цвета фона (твой Deep Space), золотых акцентов, названия шрифтов и отступы. Выпиши их в один JSON-файл или обычный текстовый список.
2. **Экспортируй графику:** Все иконки планет и знаков зодиака из этого UI Kit экспортируй в формате **SVG**. Сложи их в папку `/assets/icons/`. Агенту будет гораздо проще работать с готовыми локальными файлами.
3. **Сделай скриншоты:** Если твой агент мультимодальный (умеет "видеть" картинки, как Claude или GPT-4o), сделай скриншоты нужных экранов из Figma и прикрепи их к промпту. Визуальный контекст в сочетании с текстовым описанием творит чудеса.

## Пошаговый план для агента

Вот готовый упорядоченный план, который можно скармливать агенту по частям. Порядок здесь критически важен: мы идем от глобальной настройки темы к конкретным экранам и графике.

## План реализации фронтенда

1. **Настройка темы и дизайн-токенов в Tamagui:** Шаг 1.
Создай файл конфигурации `tamagui.config.ts`. Перенеси туда цвета из макета Figma: основной фон (`#0B0C10`), золотые и фиолетовые акценты. Настрой шрифты (Serif для заголовков, Sans-Serif для текстов) и дефолтные скругления (`border-radius: 16px`). Проверь, чтобы темная тема включалась по умолчанию.


2. **Создание атомарных компонентов карточек:** Шаг 2.
Используя примитивы Tamagui (`Theme`, `Card`, `XStack`, `YStack`), создай базовый компонент карточки. У нее должны быть правильные паддинги и скругления из макета. На основе нее сделай компонент раскрывающегося списка (`Accordion`) для экрана натальной карты.


3. **Верстка Главного экрана (Dashboard):** Шаг 3.
Собери главный экран. Размести виджет сегодняшнего гороскопа. Для шкал "Удача/Любовь/Карьера" используй компоненты прогресс-баров, стилизовав их под тонкие неоновые линии. Ниже сверстай блок "Астрологическое событие дня". Подключи локальные SVG-иконки планет, которые мы экспортировали.


4. **Отрисовка натального круга через RN Skia:** Шаг 4.
Создай изолированный компонент `NatalWheel.tsx`. Используя `Canvas` из `react-native-skia`, нарисуй два концентрических круга тонкими золотыми линиями и разбей их на 12 равных секторов (знаки зодиака). Пока что захардкодь массив с координатами планет, чтобы проверить, что линии и точки рендерятся плавно и без задержек.


5. **Интеграция с API и состояние:** Шаг 5.
Настрой базовый fetch-клиент (или Axios). Подключи экраны к эндпоинтам бэкенда, которые мы спроектировали ранее. Данные из `/api/v1/profile/natal-chart` должны прокидываться: массив градусов — в компонент Skia для динамического распределения планет на круге, а тексты интерпретаций — в Tamagui-аккордеоны ниже круга.


---

> **Совет по контролю агента:** Не проси его делать весь план целиком. Дай ему первый шаг, дождись выполнения, проверь код конфигурации Tamagui. Если всё ок — отдавай в работу второй шаг. Так ты полностью исключишь ситуацию, когда агент «галлюцинирует» и пишет тонны нерабочего кода.
